# Ethics Committee

Makes sure the values come first in every decision (`ETH-1` to `ETH-12`). People decide; agents advise.

- **Leadership accountability:** The committee chair, always a person (`ORG-3`).
- **Its product:** none of its own. It reviews by rule (`ETH-5`, `ETH-6`), and its other work is on the company's product backlog.

## Interface (`ORG-4`)

- **Offers:** Ethics-check triage; rulings, made by people; holds (answered within 2 working days); the ethics register; the acceptable-use policy.
- **A request must contain** (`ORG-5`): the item it serves, the question, the inputs, the expected output with its format and length, when it is needed, and the token budget.
- **Service level expectation:** holds answered within 2 working days. This is a starting value, for each organization to set in its own settings.
- **How to engage it:** through a board item addressed to this department (`ORG-6`), or directly to one of its roles (`ORG-5`).
